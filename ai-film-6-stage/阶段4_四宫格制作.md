## 2. 生成四宫格（GRS，逐批串行）

模型选择（默认按文档用 gpt-image-2 高质量；低成本可选 nano-banana-fast）：

**方式A：gpt-image-2（文档原用法，质量高、较慢较贵）**
```bash
python3 ../grs-image-api/api_draw.py \
  --prompt "（从 JSON 的 提示词英文 字段读取，多行用转义）" \
  --image1 "wk/项目名/03_环境母图/教室门口_RH.png" \
  --image2 "wk/项目名/03_环境母图/走廊_RH.png" \
  --image3 "wk/项目名/02_人物资产/MissLi.png" \
  --image4 "wk/项目名/02_人物资产/Liutao.png" \
  --image5 "wk/项目名/02_人物资产/Mike.png" \
  --output "wk/项目名/05_四宫格/四宫格_第1批.png"
```

**方式B：nano-banana-fast（快速低成本，参考图最多4张）**
```bash
python3 ../grs-image-api/nano_banana_draw.py \
  --prompt "（提示词英文）" \
  --aspect_ratio "3:2" --image_size "1K" \
  --image1 "..." --image2 "..." --image3 "..." --image4 "..." \
  --output "wk/项目名/05_四宫格/四宫格_第1批.png"
```

注意事项：
- 参考图先确认是 **JPEG**（WebP/GIF/PNG 需先转 JPEG，否则 API 不识别）。
- 参考图上限 8 张；一张图对应一个人物。
- 每批串行生成（GRS 不支持高并发），生成后立即检查画面是否符合 4 个 Clip。

## 3. 切分四宫格

```bash
python3 ../grs-image-api/四宫格切分.py \
  "wk/项目名/05_四宫格/四宫格_第1批.png" \
  -o "wk/项目名/06_分镜图片"
```

- 自动识别白边/黑边分割线，输出 4 张单图。
- 切分后**重命名**为 `片号_描述.png`（与 `01_剧本/Clip_设计.md` 对齐），例如：
  - `片01_MissLi送别.png`、`片02_LiuTao提问.png`…
