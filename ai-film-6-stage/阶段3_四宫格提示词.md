## 3. 编写四宫格提示词（每批一个 JSON）

模板 `04_四宫格提示词/四宫格_第1批.json`：
```json
{
  "批次": "第1批",
  "包含Clip": "片01-04",
  "说明": "场景1（教室门口）+ 场景2（走廊前3个Clip）",
  "提示词英文": "A single 2x2 grid storyboard (4-panel comic strip) based on the reference images.\n\nUse reference image 1 for background design of classroom doorway scene.\nUse reference image 2 for background design of school corridor scene.\nUse reference image 3 for Miss Li's face and clothing (green dress, female teacher).\nUse reference image 4 for Liu Tao's face and clothing (blue school uniform, boy).\nUse reference image 5 for Mike's face and clothing (blonde hair, school uniform, boy).\n\nPanel 1 (top-left): Miss Li stands at classroom doorway, smiling and waving goodbye. Medium shot, warm afternoon lighting. Classroom doorway background from reference image 1.\nPanel 2 (top-right): Liu Tao walks in school corridor, turning head to speak. Medium shot, blue lockers background from reference image 2.\nPanel 3 (bottom-left): Mike walks alongside Liu Tao, looking excited and speaking. Medium shot, corridor background from reference image 2.\nPanel 4 (bottom-right): Liu Tao nods with a proud smile while walking. Medium shot, corridor background from reference image 2.\n\nMaintain the visual style and character consistency from the reference images across all panels. Cartoon style for children's educational content, bright and cheerful colors, 8k quality. Generate image without watermarks, subtitles, or logos.",
  "提示词中文": "基于参考图片的2x2网格分镜图（4格漫画条）…（每格：角色名+动作+镜头+光线+背景来源）",
  "参考图": [
    {"文件": "wk/项目名/03_环境母图/教室门口_RH.png", "用途": "场景1背景"},
    {"文件": "wk/项目名/03_环境母图/走廊_RH.png", "用途": "场景2背景"},
    {"文件": "wk/项目名/02_人物资产/MissLi.png", "用途": "李老师角色参考"},
    {"文件": "wk/项目名/02_人物资产/Liutao.png", "用途": "刘涛角色参考"},
    {"文件": "wk/项目名/02_人物资产/Mike.png", "用途": "Mike角色参考"}
  ]

```

## 4. 提示词编写要点（严格遵守）

1. **英文结构**：整体说明 + 参考图使用说明 + 4 个 Panel 描述 + 风格要求。
2. **参考图使用说明**：每张都写「是什么类型 + 用于什么用途 + 具体特征」，
   按顺序编号 `reference image 1/2/3…`。
3. **每个 Panel 描述**：`Panel N (位置)` + 角色名+动作 + 镜头（Medium shot）+ 光线 + 背景来源。
4. **参考图上限 8 张**；一张图对应一个人物，**不要把多个人物合成一张图**。
5. **中文提示词**：英文的完整中文翻译，便于检查。
6. 只写本批涉及的场景/人物，Panel 4 与 Clip 一一对应。
