## 2. 生成视频（RH LTX 2.3，1 图 1 视频）

单条命令模板：
```bash
export RUNNINGHUB_API_KEY="账号N的API Key"

python3 ../runninghub-api/scripts/ltx2.3_无导演台_纯参数.py \
  -j "wk/项目名/07_LTX提示词/LTX_片01_MissLi送别.json" \
  --image1 "wk/项目名/06_分镜图片/片01_MissLi送别.png" \
  -r "768x512 (3:2) (横屏)" \
  -o "wk/项目名/08_视频片段/片01_MissLi送别.mp4" \
  --no-track-rh
```

## 3. 并行策略与故障处理

- **并行**：多个 RH 账号同时跑（建议 ≤6 个任务并行）。
- **账号选择**：优先余额少的账号；用完 100RH 档再换其他账号。
- **错误码 421**（API 并发上限）：等 15 秒重试；脚本内置最多 10 次重试。
- **下载失败**（退出码 8 / 读超时）：用 curl 补下：
  ```bash
  curl -L --max-time 120 -o "wk/项目名/08_视频片段/片XX.mp4" "下载链接"
  ```
- 生成后检查每个 mp4 大小/时长是否正常（`ffprobe`）。

## 4. 拼接与压缩

**4.1 生成视频列表**（按片号顺序）：
```bash
echo "file 'wk/项目名/08_视频片段/片01_MissLi送别.mp4'" > wk/项目名/视频列表.txt
# …继续追加片02、片03 … 共 N 行
```

**4.2 拼接**：
```bash
ffmpeg -f concat -safe 0 -i wk/项目名/视频列表.txt \
  -c copy wk/项目名/09_最终视频/项目名_原始.mp4 -y
```

**4.3 压缩**（如需发送飞书/上传，控制体积）：
```bash
ffmpeg -i wk/项目名/09_最终视频/项目名_原始.mp4 \
  -vcodec h264 -crf 28 -preset medium -acodec aac -b:a 96k \
  wk/项目名/09_最终视频/项目名_压缩.mp4 -y
```
> 保持原分辨率就去掉 `-vf "scale=640:426"`。

**4.4 校验成片**：
```bash
ffprobe wk/项目名/09_最终视频/项目名_压缩.mp4
```
确认能读到 duration，且实际时长 ≈ 各片段时长之和。
