## 3. 建立人物资产（本阶段核心，按 `01_剧本/人物清单.md` 逐个人物处理）

> 人物资产库已取消，不再复制旧目录。每人物的来源按清单「状态」三选一，**依次尝试，先易后难**：

### 3.1 途径一：用户提供（优先）
- 向用户要人物图片（正面清晰、无遮挡）；拿到后存 `02_人物资产/`。
- 命名：人物拼音（Liutao.png、Liutao_三视图.png）。

### 3.2 途径二：提取（SAM3 抠图）
- 从教材插图/用户图片中抠出人物（透明背景 PNG），用 skill `image-person-extraction`。
- 一张图一个人物，输出到 `02_人物资产/`。

### 3.3 途径三：生成（需用户确认）
- 仅在用户明确要求时，用 **RH** 生成人物正面图/三视图（本阶段只能用 RH，禁用 GRS）。
- 提示词严格基于课本角色描述（发色/校服/年龄），**必须以真实课本人物为基准**，不允许自由发挥新形象。

### 3.4 名字验真（每次建立后都必须做）
- 把得到的人物图**放回原始教材插图/用户图片旁边比对**：发型、服装、年龄、性别一致才算通过。
- 中文名 ↔ 英文名核对课本（刘涛=Liu Tao、杨玲=Yang Ling…）。
- 验真不过 → 不采用，退回给用户确认或换途径；**禁止张冠李戴、禁止编造名字**。
- 完成一个就在 `01_剧本/人物清单.md` 的状态列打勾，同步登记 `资产文件.md`。

## 4. 生成环境母图（RH Z-image，本阶段核心）

环境图用 RH 生成，命令模板（每张环境图一个 JSON，先手写 JSON 再调用）：

**4.1 写 JSON 提示词** `03_环境母图/环境_教室门口.json`
```json
{
  "global_prompt": "一个中国小学教室门口环境，门口、走廊、蓝色储物柜，温暖午后光线，儿童教育卡通风格，明亮欢快，无人物",
  "local_prompts": "empty scene, no people",
  "segment_lengths": "176",
  "ltxv_add_guide_multi": {"frame_indices": [0], "strengths": [1.0]}
}
```

**4.2 调用 RH 生成**
```bash
export RUNNINGHUB_API_KEY="账号N的API Key"

python3 ../runninghub-api/scripts/ltx2.3_无导演台_纯参数.py \
  -j "wk/项目名/03_环境母图/环境_教室门口.json" \
  -r "768x512 (3:2) (横屏)" \
  -o "wk/项目名/03_环境母图/教室门口_RH.png" \
  --no-track-rh
```

- 每个场景 1 张环境图，命名 `场景名_RH.png`（沿用规范，便于识别来源）。
- 出现 `错误码421`（API 并发上限）→ 等 15 秒重试；脚本内置最多 10 次重试。
- 下载失败用 curl 补下：`curl -L --max-time 120 -o "输出.png" "下载链接"`。
