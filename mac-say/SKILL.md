# Mac Say 语音播报 Skill 规范

本 Skill 用于指示 Agent 应当在任务结束、任务中断，或者遇到问题需要用户协助解决时，调用 Mac 本地 HTTP 语音服务来进行语音播报通知。

## 1. 约束与限制 (CRITICAL)

> [!IMPORTANT]
> 每次调用播报的文本内容**绝对不允许超过 30 个字**。
> 如果待播报文本超过 30 个字，Agent 必须在调用前对其进行精简、提炼，或者分段多次发送，防止长段落大声播报造成糟糕的用户体验。

> [!IMPORTANT]
> **每次播报必须注明所属项目名**（如「XX项目 已完成」）。因为多任务并行时用户会收到大量通知，缺少项目标识极易混淆。
> 文本开头用「项目名 + 空格/短横」标注，再跟状态信息，例如：`军事新闻 完成`、`AI新闻 需要协助`、`英语卡片 失败`。

---

## 2. 接口调用规范

服务通过 HTTP GET 接口进行调用：

- **基础 URL**：这两个地址通常只有一个在线。为保证触达，请优先调用本机地址，并在失败时自动降级（Fallback）调用备用地址：
  - 本机优先：`http://<MAC_SAY_PRIMARY_IP>:12345/say`
  - 备用地址：`http://<MAC_SAY_BACKUP_IP>:12345/say`
  - ⚠️ **分享注意**：`<MAC_SAY_PRIMARY_IP>` / `<MAC_SAY_BACKUP_IP>` 为占位符，请替换为你本机 Mac 语音服务的内网 IP；也可用环境变量 `MAC_SAY_URL` 直接指定完整地址覆盖。
- **请求方法**：`GET`
- **参数说明**：
  - `text` (必填)：要朗读的文本内容。**必须经过 URL 编码 (URL-encoded)**，否则可能导致 HTTP 400 错误。
  - `voice` (选填)：朗读声音角色。默认值为 `Lili`（现代自然女声）。可选的声音包括：
    - `Lili`（默认，极推荐，最为自然的中英文女声）
    - `Siri`（标准 Siri 中文女声）
    - `Yuting`（自然中文女声）
    - `Tingting`（经典中文女声，略有机械感）

### 调用示例 (cURL)

由于两个地址只有一个在线，调用时请使用带有超时和 `||`（或）逻辑的复合命令。这样 Agent 只需要执行这一行命令，如果第一个地址请求失败（如不在线），会自动尝试第二个地址：

```bash
curl --max-time 3 -G -s --data-urlencode "text=测试新版更加自然的中文声音" "http://<MAC_SAY_PRIMARY_IP>:12345/say" || curl --max-time 3 -G -s --data-urlencode "text=测试新版更加自然的中文声音" "http://<MAC_SAY_BACKUP_IP>:12345/say"
```
