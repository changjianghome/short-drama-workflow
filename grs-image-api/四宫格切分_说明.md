# 四宫格图片切分工具

将 GRS 生成的四宫格图片自动切分为 4 张单独图片，去除白边/黑边分割线。

## 模型对应的参数设置（重要）

不同模型生成的四宫格图片，分割线宽度不同，需要使用不同的参数：

| 模型 | padding | min-gap |
|:---|:---:|:---:|
| GPT (`gpt-image-2`) | 5 | 10 |
| Nano Banana (`nano-banana-fast`) | 25 | 25 |

## 命令行用法

### GPT 生成的四宫格
```bash
python3 .opencode/skills/grs-image-api/四宫格切分.py 输入图片.png -p 5 --min-gap 10 -o 输出目录
```

### Nano Banana 生成的四宫格
```bash
python3 .opencode/skills/grs-image-api/四宫格切分.py 输入图片.png -p 25 --min-gap 25 -o 输出目录
```

## 参数说明

| 参数 | 默认值 | 说明 |
|:---|:---:|:---|
| `input` | 必填 | 输入图片路径 |
| `-p, --padding` | 8 | 内缩像素数 |
| `-o, --output` | 当前目录 | 输出目录 |
| `--min-gap` | 10 | 最小分割线宽度 |
| `--threshold` | 235 | 白色检测阈值 |
| `--ext` | png | 输出格式 |

## 输出

切分后的图片命名为：`原文件名_part_01.png` ~ `原文件名_part_04.png`
