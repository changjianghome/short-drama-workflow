## 3. 调用参数控制

调用时支持通过以下 4 个命令行命名参数控制：

### 3.1 编辑提示词 (`--prompt` / `-p`，必填)
*   **节点 ID**：`15`，**属性字段**：`prompt`。
*   **作用**：描述对参考图进行的具体修改内容（例如：“将整体背景更改为黄昏，并在天空增加一个明亮的太阳”）。

### 3.2 参考图 (`--image` / `-i`，必填)
*   **节点 ID**：`14`，**属性字段**：`image`。
*   **输入方式**：
    *   **本地文件路径**：例如 `path/to/my_image.png`，脚本将自动处理上传。
    *   **网络公开直链**：例如 `https://example.com/photo.jpg`。

### 3.3 尺寸分辨率 (`--resolution` / `-r`，可选)
*   **节点 ID**：`35`，**属性字段**：`resolution`。
*   **默认值**：`"1536x1024 (3:2) (横屏)"`。
*   > [!IMPORTANT]
*   > **尺寸参数具有极其严格的固定格式要求，填错任何一个字符或空格都会导致生成尺寸错误甚至接口报错。**
*   合法支持的尺寸规格包括：
    *   `"1536x1024 (3:2) (横屏)"` (默认)
    *   `"1024x1024 (1:1) (方形)"`
    *   `"1920x1080 (16:9) (横屏)"`
    *   `"1280x720 (16:9) (横屏)"`
    *   `"1080x1920 (9:16) (竖屏)"`
    *   `"720x1280 (9:16) (竖屏)"`
    *   `"1024x1536 (2:3) (竖屏)"`
    *   `"768x512 (3:2) (横屏)"`

### 3.4 API Key (`--apikey`，选填)
*   提供 RunningHub 32 位鉴权密钥。推荐使用系统环境变量 `RUNNINGHUB_API_KEY` 进行配置。

## 4. 调用命令示例

```bash
# 1. 导出 API Key 环境变量
export RUNNINGHUB_API_KEY="您的_32位_API_KEY"

# 2. 运行脚本进行单图编辑（指定本地图片和编辑描述）
python3 scripts/单图参考编辑_bf16_基础工作流.py \
  --prompt "将整体背景改为璀璨星空，充满科幻质感" \
  --image "path/to/local_futuristic_city.png" \
  --resolution "1536x1024 (3:2) (横屏)"
```
