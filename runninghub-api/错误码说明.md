# 接口错误码说明

## 接口错误码完整对照表

> **说明**：
> * **3xx - 9xx**：`错误标识` 为大写枚举值（如 `PARAMS_INVALID`）。
> * **1xxx**：`错误标识` 为具体的英文报错句（如 `Invalid URL...`）。

| 错误码 | 错误标识 / Msg (服务端返回内容) | 中文含义与处理建议 |
| :--- | :--- | :--- |
| **301** | `PARAMS_INVALID` | **参数错误**<br>必填参数缺失或类型不符，请核对文档。 |
| **380** | `WORKFLOW_NOT_EXISTS` | **工作流不存在**<br>指定的工作流 ID 无效。 |
| **412** | `TOKEN_INVALID` | **API 路径拼写错误**<br>请检查接口 URL 是否正确。 |
| **415** | `TASK_INSTANCE_MAXED` | **独占型 API 机器数不足**<br>资源紧张，请等待 30-120 秒后重试。 |
| **416** | `TASK_CREATE_FAILED_BY_NOT_ENOUGH_WALLET` | **钱包余额不足**<br>账户余额不足，请充值。 |
| **421** | `TASK_QUEUE_MAXED` | **共享型 API 并发上限**<br>并发达上限，请自行排队或联系扩容。 |
| **423** | `TASK_NOT_FOUNED` | **未找到指定任务**<br>任务 ID 错误或已被清理。 |
| **433** | `VALIDATE_PROMPT_FAILED` | **工作流校验未通过**<br>节点参数或连接逻辑错误，请查看 msg 详情。 |
| **435** | `TASK_USER_EXCLAPI_INSTANCE_NOT_FOUND` | **未找到任务用户 API 实例**<br>48G显存机器调用时请添加参数 `"instanceType": "plus"`。 |
| **436** | `TASK_USER_EXCLAPI_REQUIRED` | **独占会员到期**<br>独占资源服务已到期。 |
| **500** | `UNKNOWN_ERROR` | **未知错误**<br>服务端异常，请联系技术支持。 |
| **801** | `APIKEY_UNSUPPORTED_FREE_USER` | **免费用户不支持 API Key**<br>请升级账户等级。 |
| **802** | `APIKEY_UNAUTHORIZED` | **API Key 未授权/已失效**<br>密钥错误或已被禁用。 |
| **803** | `APIKEY_INVALID_NODE_INFO` | **nodeInfoList 不匹配**<br>节点 ID 或字段名与工作流定义不一致。 |
| **804** | `APIKEY_TASK_IS_RUNNING` | **任务正在运行中**<br>请勿重复提交，建议轮询结果。 |
| **805** | `APIKEY_TASK_STATUS_ERROR` | **任务状态异常**<br>任务可能已被中断或取消。 |
| **806** | `APIKEY_USER_NOT_FOUND` | **未找到对应用户**<br>Key 关联的用户信息不存在。 |
| **807** | `APIKEY_TASK_NOT_FOUND` | **未找到对应任务**<br>无法查询到该 ID 的任务记录。 |
| **808** | `APIKEY_UPLOAD_FAILED` | **文件上传失败**<br>存储服务异常或网络中断。 |
| **809** | `APIKEY_FILE_SIZE_EXCEEDED` | **文件大小超出限制**<br>上传的文件体积过大。 |
| **810** | `WORKFLOW_NOT_SAVED_OR_NOT_RUNNING` | **未保存或未运行工作流**<br>请在平台**保存**并**手动运行**一次该工作流。 |
| **811** | `CORPAPIKEY_INVALID` | **企业版 API Key 无效**<br>密钥错误或无企业权限。 |
| **812** | `CORPAPIKEY_INSUFFICIENT_FUNDS` | **企业版余额不足**<br>企业账户资金耗尽。 |
| **813** | `APIKEY_TASK_IS_QUEUED` | **任务已排队**<br>任务已受理，无需重试。 |
| **901** | `WEBAPP_NOT_EXISTS` | **WebApp 不存在 或 账号地域不匹配**<br>① 应用 ID 错误；② **更常见**：应用归属地域与 key 不一致——WebApp 是 `runninghub.cn` 国内版应用，却用了国际版账号 key。排查：用 `query_account_api.py` 内置账号表逐个试，或确认应用在哪个平台创建。 |
| **1000** | `Unknown error, please retry or contact support` | **未知错误**<br>请重试或联系支持。 |
| **1001** | `Invalid URL, please check your link` | **请求链接无效**<br>请检查您的调用链接。 |
| **1002** | `Invalid API Key, please check your credentials` | **API Key 无效**<br>请检查您的密钥。 |
| **1003** | `Rate limit exceeded, please slow down requests` | **请求频率超限**<br>请降低请求速度。 |
| **1004** | `Task not found, please check the task ID` | **任务不存在或已过期**<br>请检查任务 ID。 |
| **1005** | `Internal server error, please retry later` | **系统内部错误**<br>请稍后重试。 |
| **1006** | `Task execution timed out, please retry` | **任务执行超时**<br>请重试。 |
| **1007** | `Invalid parameters, please check your input` | **参数校验失败**<br>请检查输入参数。 |
| **1008** | `File size limit exceeded` | **文件大小超出限制**<br>请压缩文件后重试。 |
| **1009** | `HTTP method not supported, please check documentation` | **请求方法不支持**<br>请查阅文档确认 (GET/POST)。 |
| **1010** | `Service unavailable, please retry later` | **服务暂不可用**<br>请稍后重试。 |
| **1011** | `System is currently busy, please retry later` | **系统繁忙**<br>请求量大，请稍后重试。 |
| **1012** | `Service response exception, please contact support or retry later` | **上游服务响应异常**<br>请联系技术支持或稍后重试。 |
| **1013** | `File processing failed, please check the URL or retry` | **文件处理失败**<br>请检查链接或重新上传。 |
| **1014** | `Access Denied: Standard Model API is restricted to Enterprise-Shared API Keys only.` | **访问被拒绝**<br>标准模型 API 仅限企业级-共享 API Key 调用。 |
| **1015** | `Generation failed, please try again.` | **生成失败**<br>请重试。 |
| **1101** | `Node info error` | **节点信息异常**<br>工作流节点数据解析错误。 |
| **1501** | `Content verification failed, please modify your prompt or images` | **内容审核未通过**<br>请修改提示词或图片。 |
| **1504** | `Model timed out, please retry later` | **模型响应超时**<br>请稍后重试。 |
| **1505** | `Photorealistic real people are prohibited, please modify your prompt or image` | **禁止生成真人**<br>请修改提示词或参考图。 |
